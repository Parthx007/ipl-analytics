# IPL Analytics Project

## Overview

This project analyzes IPL match and ball-by-ball data using Python, Pandas, Matplotlib, and Seaborn.

The goal was to answer business-style cricket analytics questions and perform exploratory data analysis (EDA) on IPL datasets.

## Dataset

Source: IPL Matches and Deliveries Dataset

Files used:

* matches.csv
* deliveries.csv

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Git & GitHub

## Analyses Performed

### Team Performance

* Teams with the most IPL wins
* Highest team scores in IPL history
* Teams with the most 200+ scores

### Batting Analysis

* Top 10 run scorers
* Top 10 six hitters

### Bowling Analysis

* Top wicket takers

### Match Insights

* Toss impact on match results
* Best chasing teams in IPL

## Key Learnings

* Data Cleaning
* GroupBy Operations
* Data Aggregation
* Data Visualization
* Merging Datasets
* Git and GitHub Workflow
